# 📊 Excel Sales Dashboard Project

This project demonstrates how raw sales data can be transformed into meaningful insights using **Microsoft Excel**, **Power Query**, **Pivot Tables**, **Charts**, and **Slicers**.  
It includes both the **source dataset** and the **final interactive dashboard**.

---

## 📂 Project Files
- `source-data.xlsx` → Raw sales dataset before cleaning  
- `sales-dashboard.xlsx` → Final interactive dashboard with Pivot Tables, Charts, and Slicers  
- `screenshot.png` → Snapshot of the dashboard  

---

## 🚀 Project Workflow / Steps
1. **Get Data from Excel File Using Power Query**  
   - Import the raw dataset into Power Query for transformation.  

2. **Apply Transformation Steps**  
   - Change **date format** to proper Excel date type  
   - Calculate **Total Sales** = `Quantity × Unit Price`  
   - Clean and prepare data for Pivot Tables  

3. **Load Data into Excel Pivot Tables**  
   - Generate all required Pivot Tables for KPI calculation and analysis  

4. **Create Dashboard**  
   - Design and layout the dashboard  
   - Add charts, visuals, and interactive slicers for dynamic reporting  

---

## 📊 Dashboard Insights & KPIs

### Key Performance Indicators (KPIs)
- **Total Sales** – Overall revenue generated  
- **Average Sales** – Average revenue per transaction  
- **Total Transactions** – Count of all transactions  
- **Total Quantity** – Total units sold  

### Visualizations
- **Ship Mode Sales % Wise** – Pie Chart  
- **Zone Wise Sales %** – Donut Chart  
- **Month Wise Quantity Sold** – Line Chart  
- **Top 5 Cities Sales Wise** – Column Chart  
- **Category Wise Transactions Count** – Bar Chart  
- **Consumer Type Wise Quantity Ordered** – Bar Chart  

### Interactive Slicers
- **Region Slicer** – Filter dashboard by region  
- **Year Slicer** – Filter dashboard by year
